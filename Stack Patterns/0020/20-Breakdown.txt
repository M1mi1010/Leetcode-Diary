Final attempt:
- Check the length of the string, if it's an odd length, return false
- For each character, push it if its an opening bracket 
- If not, check if the stack is empty (before popping). If it is return false
- Then pop the item off the top of the stack, and check if it matches c

- Return stack.isEmpty() - incase there are open brackets left on the stack
